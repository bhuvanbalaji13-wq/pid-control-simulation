# PID Control System Simulation

## Overview
This project demonstrates a basic PID (Proportional-Integral-Derivative) control system. It shows how tuning PID parameters improves system stability and response.

---

## Objective
- Understand system behavior without control
- Apply PID control
- Compare system response before and after tuning

---

## What is PID?
PID controller adjusts system output based on:
- Proportional → reacts to current error  
- Integral → reacts to accumulated error  
- Derivative → predicts future error  

---

## Implementation
- Simulated system using Python
- Applied PID control algorithm
- Compared uncontrolled vs controlled response

---

## Results
- Reduced overshoot  
- Faster settling time  
- Improved stability
